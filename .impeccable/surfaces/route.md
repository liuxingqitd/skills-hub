# Web Landing Page

- Scope and mode: Web route `/`, Persuade.
- Audience and job: Developers using several AI coding agents need to understand that Skills Hub makes local skill state legible and gives them one safe place to resolve differences.
- Primary action: Download the macOS or Windows desktop release. Secondary actions: inspect the MIT source and open the local Web workbench at `/dashboard`.
- Proof: A realistic four-agent status matrix, filesystem paths, `SKILL.md`, SHA-256 comparison, explicit sync states, global-rule editing, and source discovery.
- Constraints: No cloud/database implication, fabricated metrics, testimonials, or security claims. Demonstration values are labeled.
- Chosen direction: **Workbench Cinema / 一张会呼吸的工作台**, selected from surface concept seed `2d6997ff`; approved comp `.impeccable/mocks/decision/workbench-cinema.webp`.
- Memorable moment: The product name leads, then the real workbench rises into the same first viewport with multiple synced, missing, and drifted states already visible.

## Direction Contract

**THESIS:** Turn cross-agent skill drift into one legible local workbench; refuse the generic SaaS hero that hides the product behind claims.

**OWN-WORLD:** Cool near-white field, white bordered work surfaces, dark ink, disciplined sync-green, compact literal file facts, 8px controls, and 14px panels.

**STORY:** See the state matrix, understand filesystem truth and explicit sync, then download or inspect the source.

**FIRST VIEWPORT:** Restrained nav; dominant “Skills Hub”; supporting Chinese proposition and two actions; the dashboard starts inside the fold and shows multiple rows and all three states.

**FORM:** Grounded structural candidate 5 of 7, seed `2d6997ff`, chosen option `workbench-cinema`.
